# 裝備欄位對應草案（待確認）

詞綴表寫的是**物品種類**（16 種），角色卡寫的是**身體欄位**（10 格），
兩套詞彙對不起來。Phase 4 要檢核「這條詞綴能不能附在這件裝備上」就需要
一張對應表。

這份是草案，**尚未寫進資料庫**。確認後我再建表並接上驗證。

---

## 一、可直接對應（9 項，信心高）

| 詞綴部位 | 角色卡欄位 | 依據 |
|---|---|---|
| 頭環 | 頭 | 名稱直接對應 |
| 手套 | 手 | 名稱直接對應 |
| 手環 | 手臂 | 手環戴在前臂，範例卡的「手臂」欄應指此 |
| 鎧甲 | 身體 | 名稱直接對應 |
| 披風 | 披風 | 完全同名 |

## 二、角色卡沒有對應欄位（5 項）

範例卡把這些全塞在右側的「其他」欄。它們都是手持物品，建議**新增三個
明確欄位**而不是繼續用「其他」：

| 詞綴部位 | 建議新增的欄位 | 說明 |
|---|---|---|
| 武器 | 主手 | 一般近戰／遠程武器 |
| 武器(弓) | 主手 | 武器的子類，僅弓類可用的詞綴 |
| 魔導槍械 | 主手 | 另一種武器類別，與「武器」的詞綴清單不同 |
| 法杖 | 主手 或 副手 | 施法者的主要裝備；是否佔主手需確認 |
| 盾牌 | 副手 | 與武器互斥 |

**需要你確認的**：
1. 是否採用「主手／副手」這兩個新欄位？還是你另有慣用的叫法？
2. 雙手武器是否同時佔用主手與副手（進而不能帶盾牌）？
3. 法杖佔主手還是副手？能不能和武器同時裝備？

## 三、語意不明，需要你定義（2 項）

### 「主要裝備」

出現在 3 條詞綴的部位欄。從上下文看不出確切範圍：

- 〈精金〉的部位是「武器／主要裝備／盾牌」，其詞綴效果寫
  「武器: 攻擊命中增加…」與「主要裝備、盾牌: 物抗…」
  → 這裡「主要裝備」與武器、盾牌並列，看起來指**鎧甲**
- 〈爆擊球〉的部位是「主要裝備／武器／手套／魔導槍械」
  → 這裡又與武器、手套並列

**問題**：「主要裝備」是指鎧甲，還是「角色當下的主要裝備品」這種浮動概念？
若是後者，Phase 4 無法做靜態檢核。

### 「全」

只出現在 1 條詞綴。推測是「任何部位皆可附加」。

**問題**：是否真的是所有部位都可以，包含武器與盾牌？

## 四、確認後的處理

你確認上述三組問題後，我會：

1. 在 `db/schema.sql` 新增 `equipment_slot`（權威欄位清單）與
   `affix_slot_mapping`（詞綴部位 → 裝備欄位）兩張表
2. 把對應關係寫成 `data/errata/_裝備欄位對應.yaml`，連同你的裁示理由
3. 在 `tools/validate.py` 加上檢核：每個詞綴部位都必須對應到至少一個欄位
4. Phase 4 的裝備配置介面即可依此擋下不合法的詞綴附加
