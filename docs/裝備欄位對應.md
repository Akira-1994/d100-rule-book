# 裝備欄位對應

詞綴表寫的是**物品種類**（16 種），角色卡寫的是**身體欄位**。兩套詞彙原本
對不起來，武器與盾牌甚至不在範例卡的十格裡（被塞在右側的「其他」欄）。

**2026-09-20 由規則書作者逐項確認完畢，已寫進資料庫。**
對應資料在 [`data/errata/_裝備欄位對應.yaml`](../data/errata/_裝備欄位對應.yaml)，
每一筆都附裁示理由。

---

## 裝備欄位（12 格）

```
頭 / 手 / 手臂 / 身體 / 披風 / 腰帶 / 鞋子 / 項鍊 / 戒指（左）/ 戒指（右）/ 主手 / 副手
```

前十格沿用「法師範例」那張角色卡；**主手與副手是這次新增的**。

值得一提的是，「主手／副手」不是我們發明的詞 —— 規則書本身就在用：

- 〈武器使用(充能斧)〉：「你的**主手**需綁定一個單手武器、**副手**需綁定一個盾牌」
- 〈雙手武器大師〉：「每1.5技能等級多1次**主手**攻擊次數」
- 〈戰鬥專攻〉：「雙武器戰鬥：你的**副手**在此技能…」

範例卡把手持物全塞在「其他」欄，反而偏離了規則書自己的用語。

## 兩個語意不明部位的裁示

### 「主要裝備」＝ 鎧甲（身體欄）

只有 3 條詞綴與 4 種素材使用這個部位。資料本身就支持這個結論：

- 〈精金〉的部位是「主要裝備／武器／盾牌」，效果寫
  「武器: 攻擊命中增加20」與「**主要裝備、盾牌: 物抗…**」
- 〈密銀〉寫「法杖: 法術檢定增加5」與「**主要裝備、盾牌: 法抗…**」
- 〈龍麟〉〈五色龍龍麟〉本身就是防具素材

也就是說，每次「主要裝備」出現在效果敘述裡，配的都是與盾牌並列的**防禦**
效果，而武器／法杖配的是攻擊效果。

### 「全」＝ 所有部位

只有〈吉兆〉使用，效果是「每日重骰次數 = 附有此詞綴之魔法物品的總加值÷6」，
本來就與裝備種類無關。作者確認包含武器與盾牌在內的所有部位都可以。

## 不做硬性檢核的規則

以下由作者裁示交給 DM 判斷，Phase 4 **只警告不阻擋**（符合本專案
「軟性驗證」的設計）：

- **雙手武器只佔主手**，副手是否還能放東西由 DM 裁定
- **四種武器類部位（武器、武器(弓)、魔導槍械、法杖）主手副手都能放**
- **盾牌主副手都可**，雖然〈武器使用(充能斧)〉寫的是「副手需綁定一個盾牌」

## 驗證

`tools/validate.py` 新增三項檢查：

1. 每個實際出現過的詞綴部位（含素材部位）都必須對應到至少一個裝備欄位
2. 對應到的欄位必須存在於 `equipment_slot`
3. 沒有任何詞綴部位對應到的欄位會發出警告

目前 16 種詞綴部位全數有對應，12 個欄位全數被使用到。
